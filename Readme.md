# Web Technology Assignments

A comprehensive collection of 6 web technology assignments covering full-stack web development with modern frameworks and best practices.

## 📚 Assignments Overview

| # | Assignment | Technology | Level | Description |
|---|-----------|-----------|-------|-------------|
| 1 | Electricity Bill Calculator | PHP + HTML/CSS | Beginner | Server-side tariff calculation with form processing |
| 2 | Animated Clock Dashboard | React + CSS3 | Intermediate | Real-time analog/digital clocks with timezone manager |
| 3 | Bill Calculator (Java) | Servlet + JSP | Intermediate | Enterprise Java web application for calculations |
| 4 | Student Result Calculator | React + CSS3 | Intermediate | Grade calculation and result display system |
| 5 | Student Management System | Spring Boot + PostgreSQL | Advanced | RESTful backend API with database integration |
| 6 | Online Book Store | Node.js + Express + PostgreSQL | Advanced | Full-stack application with authentication & real-time |
| 7 | Online Book Store v2 | React + Spring Boot + PostgreSQL | Advanced | Full-stack with modern architecture and JWT auth |
| 8 | UML Class Diagram Generator | React + Creately API | Advanced | Interactive diagram design with Java code generation |

### Prerequisites
- **PHP**: XAMPP or any PHP-enabled server
- **React**: Node.js (v14+) and npm
- **Java**: JDK 17+, Maven, Tomcat
- **Spring Boot**: JDK 17+, Maven, PostgreSQL
- **Node.js**: Node.js (v14+), npm, PostgreSQL
